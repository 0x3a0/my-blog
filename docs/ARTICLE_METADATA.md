# 文章元数据

在 Notion 属性中维护元数据，正文用于文章内容。

| 来源 | 规则 |
| --- | --- |
| 页面标题 | 唯一标题来源，修改标题不改变链接 |
| to-blog-site | 复选框，勾选允许公开并持续同步 |
| Published | 作者填写，用于显示、排序及按年归档 |
| category | 单选；缺失或未选时保留空值，显示“未分组” |
| description | 文本；缺失或空白时保留空值，不生成摘要 |
| 最后编辑时间 | 博客更新时间 |
| Tags | 供作者整理，不自动作为分类 |

选定文章缺少 Published 时整次失败，报告文章并保留旧站点。未来日期照常显示、排序及归档；是否发布仍由 to-blog-site 控制，不用日期定时发布。

Published 纯日期保持作者填写日；带时间则按北京时间显示及归档；日期区间只取起始日期，结束日期不参与博客规则。

“未分组”仅是空分类的显示名称，不补写至 Notion，当前也不增加分类页面。见[需求记录](./NOTION_REQUIREMENTS.md)。
