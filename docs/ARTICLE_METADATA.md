# 文章元数据

本文说明[功能规格](./spec/README.md)中的文章元数据规则。

作者在语雀文章正文开头填写 YAML frontmatter。同步时提取为博客文章元数据，读者看到的正文中移除该段。

文章分类使用 `category` 字段，不使用 `type`；分类由作者填写，不按语雀目录分组自动推导。“博客发布”分组用于选定允许公开的文章。

## 字段

- 标题唯一来源是语雀文章标题，作者不在 frontmatter 中重复填写 `title`。
- `description` 选填：优先使用 frontmatter 中的值，缺省时使用语雀摘要；仍无摘要时从移除元数据后的正文生成短摘要。
- `category` 选填：缺省为“随笔”。

```yaml
---
description: "文章摘要"
category: "技术"
---
```

整段元数据可以省略。已填写但格式错误时，整次同步失败，保留线上完整版本；不能把损坏的元数据当作未填写。
