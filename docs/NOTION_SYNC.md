# Notion 同步

- 首版读取指定 My blog 文章库和选定的数据源。
- 每日北京时间 06:00 计划触发，完成时间受排队与构建影响。
- 仅发布 to-blog-site 勾选文章，更新最新保存的标题、属性和正文。
- 稳定页面身份决定地址；Published 作文章日期，最后编辑时间作更新时间。
- 撤回在下一次完整成功同步生效，见[发布边界](./ARTICLE_PUBLISHING.md)。

## 完整发布

读取、属性校验、转换、必需图片或构建任一失败，整次不发布，保留上次完整站点。

完整可信列表才能判断撤回。正常空集合可以提交为空站点；异常或权限失效不能伪装成空集合。

## 接入状态

入口为 `pnpm notion:sync`；读取与转换后执行真实 Astro 构建，只在末次一致性检查通过后替换 `.artifacts/notion-published`。同一输出的同步互斥，避免并发覆盖。

线上使用 `pnpm notion:publish`，从上一版站点的 `blog-publication.json` 取得已公开文章身份，再确认撤回。该文件仅含公开文章 ID 和来源指纹，不包含 Token、私有正文或数据库 ID。

已验证一篇真实文章。分页、图片、特殊块及失败保护经过可控返回测试；真实图片、撤回和线上定时发布的剩余验收见[记录](./NOTION_ACCEPTANCE.md)。接口细节见[读取契约](./spec/API_CONTRACT.md)。
