# 实现步骤

功能范围与验收依据见[功能规格](./spec/README.md)。尚未开始功能实现。

## 接口验证

使用指定知识库中的代表文章，验证私密内容读取、最新保存的标题与正文、frontmatter 分隔线和字段保留，以及图片访问。对比编辑、保存、清空正文与修改标题等状态，核验点见[接口要点](./YUQUE_API.md)。

不能可靠获取最新保存内容时，报告具体缺口并重新讨论，不能悄悄改为已发布版本。

## 同步流程

读取完整知识库目录，按“博客发布”分组及其子分组识别选定文章，使用稳定文档 ID 去重及建立博客地址。获取最新保存内容，解析元数据，处理图片，生成本地 Markdown 内容，并通过内容校验与静态构建后发布。

全部内容与必需资源验证成功后，才发布更新和下架变更。每天北京时间 06:00 计划触发；规则见[语雀同步](./YUQUE_SYNC.md)。

## 页面实现

接通首页文章链接，实现稳定的文章详情地址、正文排版与目录，再实现按年归档页面和 Header 的 `blogs` 入口。页面与资源地址尊重现有部署基础路径，视觉沿用首页，页面范围见[文章页面](./ARTICLE_PAGES.md)。

继续使用 Astro、严格 TypeScript、Tailwind CSS 4、daisyUI 与 pnpm。现有 Astro 已提供 frontmatter 解析工具，优先复用现有依赖。
