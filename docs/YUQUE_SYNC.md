# 语雀同步

本文说明[功能规格](./spec/README.md)中的同步规则。

- 每天北京时间（Asia/Shanghai）06:00 计划触发一次自动同步；实际完成时间受任务排队与构建耗时影响。
- 首版只接入一个指定的语雀知识库。
- 文章统一在语雀修改，博客同步更新文章内容和标题。
- 作者取消选定文章后，在下次成功同步时从博客下架。
- 标题更新后博客链接保持不变，页面显示同步后的新标题。

同步“博客发布”分组及其子分组中的文章，允许这些文章在语雀保持私密，具体读取权限需验证。发布边界见[文章发布边界](./ARTICLE_PUBLISHING.md)。

同步最新保存的标题与正文，不要求语雀已发布版本；文章保持在选定分组中时，后续保存的修改也会在下一次同步时进入博客。

接口字段如何可靠对应最新保存内容仍需验证，不能把已发布版本正文当作最新草稿使用。接口依据见[语雀接口要点](./YUQUE_API.md)。

## 同步失败

某篇文章或必需图片同步失败时，整次不发布，保留线上上一次完整版本，并将任务标记为失败。只有完整同步成功后才更新博客。

接口异常或失去读取权限不视为作者撤回文章，不能据此下架。

发布范围见[文章发布边界](./ARTICLE_PUBLISHING.md)。
