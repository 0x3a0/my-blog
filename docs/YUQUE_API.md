# 语雀接口要点

依据：[本地 OpenAPI 文档](./yuque_openapi_20260722.html)，版本 2.0.1。以下是接口能力，不代表已确定的产品规则。

## 选定与状态

- 文档列表可通过 `optional_properties=tags,latest_version_id` 获取标签和最新已发版本 ID，每页最多 100 条。
- 目录接口提供文档、外链、分组节点及父子关系，可用于识别指定分组中的文档。
- 文档列表没有按标签过滤的查询参数，需要同步程序取得列表后筛选。
- `status` 区分草稿（0）与发布（1）；`public` 区分私密（0）、公开（1）、企业内公开（2）。二者不是同一个状态。

## 已发布版本

- `GET /api/v2/doc_versions?doc_id=…` 按时间倒序返回最近 100 个已发布版本。
- `GET /api/v2/doc_versions/{id}` 提供版本标题、原始正文、Markdown 正文 `body_md` 和 HTML 正文。
- 若产品选择只同步已发布版本，可用 `latest_version_id` 获取同一版本的标题与正文；不应混用当前标题与历史正文。
- 普通文档详情同时提供 `body_draft` 与 `body`，但文档没有承诺 `body` 一定对应最新已发布版本。
- 接口文档没有说明语雀界面中的保存动作何时产生已发布版本，不能据此要求作者必须额外点击某个界面按钮。

## 待验证

- 普通详情字段未承诺对应最新保存内容：需用同一篇文章核验首次保存、已发版、保存未发版修改、清空正文和修改标题等状态。
- `body_draft` 的实际格式及空值含义、`body_html` 是否反映草稿、标题与正文是否对应同一保存状态，均未明确。不能简单用 `body_draft || body` 回退，也不能用已发版本的 `body_md` 冒充最新草稿。
- 文档没有图片外链匿名可访问或长期有效的承诺，也没有普通正文中公式、流程图和嵌入卡片的转换规则。
- 鉴权使用 `X-Auth-Token`，具体账户可读取哪些私密内容仍需验证，不能将读取权限直接当作博客公开发布授权。
- 标签字段被建模为单个对象，多标签的实际返回形状仍需核验。版本接口不提供摘要、封面和标签。

若接口不能可靠获取最新保存内容，必须报告能力缺口，不能私自将产品规则改为只同步已发布版本。
