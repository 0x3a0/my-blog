# 状态标签

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 尚待评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 可交给 AI 实现 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 决定不处理 |

技能提及任务状态时使用对应标签。补齐仓库缺少的标签，保留已有标签及其设置。标签用于分类，不会自动启动任务。
