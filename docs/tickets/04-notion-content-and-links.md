# 04：保留 Notion 正文结构与文章链接

状态：已发布 [GitHub Issue #5](https://github.com/0x3a0/my-blog/issues/5)；实现与剩余验收见[验收记录](../NOTION_ACCEPTANCE.md)。

## Parent

[Notion 正式规格 #1](https://github.com/0x3a0/my-blog/issues/1)。覆盖用户故事：32–33、54–55、70–75、78。

## What to build

作者在 Notion 使用普通标题、列表、代码、表格、引用、提示框和分栏，博客完整保留内容及阅读顺序；已同步文章之间可在博客内跳转，子页不会自动公开。

## Acceptance criteria

- [ ] 处理增强 Markdown 的普通标题、段落、列表、代码、表格、引用及相关格式标记，不把未知标记静默删掉。
- [ ] 提示框转引用，并排栏按内容顺序转单栏，保留文字、基本结构和阅读顺序。
- [ ] 转换后的正文通过真实构建呈现可读代码、表格、引用和目录，包含中文及嵌套结构验证。
- [ ] 先完整确定本次发布集合；指向本次选定并成功同步文章的源链接转为稳定博客地址，并保留可可靠映射的链接语义。
- [ ] 其他链接保留源地址，不生成未发布文章的详情入口；子页面不自动展开，只有独立加入文章库并勾选才作为博客文章。
- [ ] 检查截断、未知块和未知占位，补读后仍无法完整转换则失败；不能当作空正文或略过缺失部分。
- [ ] 首版遇到公式、音视频或 PDF 播放器、复杂嵌入等范围外内容，指出文章及内容类型，整次失败保留旧站点。
- [ ] 使用可控 Notion 正文经真实同步及构建覆盖普通格式、提示框、分栏、内部与外部链接、子页和转换失败。
