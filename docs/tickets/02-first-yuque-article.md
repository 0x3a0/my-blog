# 02：将一篇选定的语雀文章同步到可阅读详情页

状态：待确认，尚未发布。对应规格用户故事：1、2、3、8、12、13、14、26、27、28、29、40。

## Parent

[语雀同步、文章详情与按年归档规格 #1](https://github.com/0x3a0/my-blog/issues/1)。

## What to build

作者仅在语雀写作，运行一次同步后，可在本地生成网站中读到指定“博客发布”分组中的一篇普通文章。先验证真实接口，再走通最新保存内容到文章集合和详情页的完整路径；本任务尚不启用定时线上发布。

## Acceptance criteria

- [ ] 使用一个指定知识库中的代表文章验证实际接口：首次保存、已发版、保存未发版修改、清空正文和修改标题，并记录标题、正文、格式、更新时间的对应关系。
- [ ] 验证选定私密文章在读取权限有效时可读，并核验正文开头 YAML 分隔线是否保留、必需图片能否公开读取；验证记录与固定返回移除凭据和个人内容。
- [ ] 最新正文读取区分字段缺失与合法空正文，不凭简单空值回退选择历史已发布正文；接口无法满足最新保存契约时报告明确缺口，不宣称接入成功。
- [ ] 一次同步的公开入口接收知识库、博客发布分组、鉴权与输出配置；真实读取与可控测试返回共用同一入口。
- [ ] 选定的基础普通文章生成候选内容，语雀标题是唯一标题来源，稳定文档身份决定地址，创建日期与更新时间沿用经验证的源字段。
- [ ] 保存未发版修改与改标题后再次同步，详情显示最新内容且地址不变；合法空正文不重新出现旧正文。
- [ ] 读取、转换或构建失败时任务失败，候选输出不覆盖上次完整结果；凭据不出现在日志、生成内容、网页或可重放测试返回中。
- [ ] 使用可控语雀返回运行真实同步与静态构建，验证最后生成的首页入口及详情；实际接入的知识库、分组和凭据由执行环境提供。
