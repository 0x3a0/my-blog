# 03：同步完整发布分组并正确撤回文章

状态：待确认，尚未发布。对应规格用户故事：4、5、6、7、9、10、11、23、24、25、32、37、38、59。

## Parent

[语雀同步、文章详情与按年归档规格 #1](https://github.com/0x3a0/my-blog/issues/1)。

## What to build

作者通过“博客发布”分组及子分组选定多篇文章，博客只导入这些文章。移出选定范围后，下次完整成功同步撤回列表入口与详情正文；读取异常不会误下架。

## Acceptance criteria

- [ ] 完整读取目录及必要分页，识别唯一配置的博客发布分组及全部子分组；分组外的文章、笔记和草稿不导入。
- [ ] 基于稳定语雀文档身份去重，重复目录引用只生成一篇；改标题或在选定范围内移动不改变文章地址。
- [ ] 分组选择表示公开授权，私密或草稿状态不自行取消选定；文章分类不按目录层级推导。
- [ ] 外链节点不作为文章正文；独立工作表、画板、数据表等未支持内容不导入，并在同步结果中列出。
- [ ] 完整可信结果才能决定撤回；缺失配置、分组无法唯一确定、分页未完成、无权限或接口异常均使本次任务失败，保留上次内容。
- [ ] 移出范围后的成功同步同时去掉所有已有列表入口与详情正文，旧地址不再提供内容；其余文章继续可读。
- [ ] 完整成功且选定集合为空时产生正常空状态，不把预览样例当作已同步文章。
- [ ] 通过真实同步及静态构建覆盖嵌套分组、分页、重复引用、范围内移动、撤回、空集合与权限失败，并检查最终页面及保留结果。
