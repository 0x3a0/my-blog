# 05：可靠撤回文章并保留失败前的完整站点

状态：2026-10-13 按作者指示及当前全量发布方案关闭 [GitHub Issue #6](https://github.com/0x3a0/my-blog/issues/6)；验证边界见[验收记录](../NOTION_ACCEPTANCE.md)。

## Parent

[Notion 正式规格 #1](https://github.com/0x3a0/my-blog/issues/1)。覆盖用户故事：10–11、24、28–29、35–38、59、76–80。

## What to build

每次完整读取当前勾选集合并替换全站，未返回的旧文章自然从列表和详情撤回；本次接口错误、其他文章失败或构建失败时，网站保留上一次完整状态。

## Acceptance criteria

- [x] 按完整成功查询的勾选集合替换全站，移除未返回旧文章的首页、归档及详情正文，不读取旧文章或发布清单。
- [x] 本次必要请求的 404、权限错误、异常游标、读取超限或不完整查询均停止发布，不作为正常空集合。
- [x] 完整可信空集合可发布为空站点，并展示空状态，不把示例内容或上一轮文章混入候选。
- [x] 有效空正文允许同步并清空旧正文，详情仍显示标题和属性；未取得正文、截断和未知内容不属于有效空正文。
- [x] 同次同步包含新增、更新和撤回时，任一读取、校验、转换、必需图片或构建失败都保留整个旧站点，包括原本计划撤回的文章。
- [x] 重试不重复导入；候选提交失败可恢复旧快照，并发任务不互相覆盖，也不提前改写正式输出。
- [x] 用可控 Notion 返回从已有站点运行第二次真实同步和构建，验证各类撤回、可信空集合、空正文及混合失败后的最终页面和资源。

作者确认按上述实现及自动回归关闭；真实文章取消勾选、移动及回收站操作未在本轮执行，保留为后续使用复查，不记为已验证。
