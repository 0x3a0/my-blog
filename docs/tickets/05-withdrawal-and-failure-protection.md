# 05：可靠撤回文章并保留失败前的完整站点

状态：已发布 [GitHub Issue #6](https://github.com/0x3a0/my-blog/issues/6)；实现与剩余验收见[验收记录](../NOTION_ACCEPTANCE.md)。

## Parent

[Notion 正式规格 #1](https://github.com/0x3a0/my-blog/issues/1)。覆盖用户故事：10–11、24、28–29、35–38、59、76–80。

## What to build

作者取消勾选、移出文章库或删除文章后，下次完整成功同步统一移除列表和详情正文；读取权限变化、其他文章失败或构建失败时，网站保留上一次完整状态。

## Acceptance criteria

- [ ] 可靠确认取消勾选、移出文章库或放入回收站后，成功同步移除首页、归档及详情正文，旧地址不再提供正文。
- [ ] 404、权限不足、异常游标、读取超限或不完整查询不得单独成为撤回依据，报告失败而非提交空集合。
- [ ] 完整可信空集合可发布为空站点，并展示空状态，不把示例内容或上一轮文章混入候选。
- [ ] 有效空正文允许同步并清空旧正文，详情仍显示标题和属性；未取得正文、截断和未知内容不属于有效空正文。
- [ ] 同次同步包含新增、更新和撤回时，任一读取、校验、转换、必需图片或构建失败都保留整个旧站点，包括原本计划撤回的文章。
- [ ] 重试不重复导入；候选提交失败可恢复旧快照，并发任务不互相覆盖，也不提前改写正式输出。
- [ ] 用可控 Notion 返回从已有站点运行第二次真实同步和构建，验证各类撤回、可信空集合、空正文及混合失败后的最终页面和资源。
- [ ] 用实际文章核实取消勾选、移动及回收站状态；无法区分权限失效与真实撤回时保持旧站点并报告缺口。
