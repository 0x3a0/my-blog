# 06：通过 Header 的 blogs 浏览按年归档

状态：待确认，尚未发布。对应规格用户故事：43、44、45、46、47、48、49、50。

## Parent

[语雀同步、文章详情与按年归档规格 #1](https://github.com/0x3a0/my-blog/issues/1)。

## What to build

读者从 Header 的小写 blogs 入口进入全部文章页面，按年份浏览所有博客文章并进入详情。可以先用本地代表文章完成并展示，无需等待语雀接入。

## Acceptance criteria

- [ ] Header 显示小写 blogs，入口使用站点基础路径且可到达全部文章页。
- [ ] 与首页、详情共用真实文章集合，全部文章一次展示，年份倒序、年内按创建日期倒序，按 Asia/Shanghai 确定年份。
- [ ] 桌面端左侧年份、右侧文章行；每行只展示标题、分类、进入详情的箭头，使用细分隔线与年份组间留白，遵循已确认参考图。
- [ ] 移动端年份在组内文章上方，长标题正常换行；每一行都能进入对应详情页。
- [ ] 不增加分页、搜索、分类筛选、摘要行、标签页或新封面；空集合显示正常空状态。
- [ ] 通过真实静态构建验证多年份排序、北京时间跨年、全部文章覆盖、分类与详情链接；桌面和移动端对照参考布局查看。
- [ ] 新增或撤回文章后重新构建，归档与文章集合一致，不保留已经不存在的文章入口。

## Blocked by

1：从首页进入可阅读的文章详情页。
