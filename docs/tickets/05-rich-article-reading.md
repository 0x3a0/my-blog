# 05：公开阅读语雀文章图片与结构化正文

## Parent

[语雀同步、文章详情与按年归档规格 #1](https://github.com/0x3a0/my-blog/issues/1)。

## What to build

读者无需登录语雀即可阅读选定普通文章的图片、代码块、表格与引用，并通过文章目录跳转。文章内容与必需图片无法可靠处理时本次同步失败。

## Acceptance criteria

- [ ] 依据已验证的正文格式将普通文章转换为可可靠静态渲染的内容；代表文章中的图片、代码块、表格与引用正常阅读。
- [ ] 必需图片同步到无需语雀登录即可访问的博客资源，生成资源与正文链接遵守站点基础路径。
- [ ] 详情页从最终正文标题生成可跳转的文章目录，目录链接命中对应标题，不包含已移除的 frontmatter。
- [ ] 移动端标题、代码块与表格可阅读，较宽内容的展示不破坏页面布局；优先使用 Tailwind CSS 4 与 daisyUI。
- [ ] 普通正文无法可靠转换或必需图片下载、校验失败时整次失败，保留上次完整结果，不能留下缺图或缺损文章。
- [ ] 不额外承诺数学公式、专门流程图及复杂嵌入卡片保真；发现影响普通文章可靠转换的内容时明确报告缺口。
- [ ] 使用去敏代表返回运行真实同步与静态构建，检查匿名可用图片、正文结构、目录锚点、资源子路径和失败保留，并完成桌面与移动端查看。
