# 03：让 Notion 文章图片长期公开可读

状态：已发布 [GitHub Issue #4](https://github.com/0x3a0/my-blog/issues/4)；实现与剩余验收见[验收记录](../NOTION_ACCEPTANCE.md)。

## Parent

[Notion 正式规格 #1](https://github.com/0x3a0/my-blog/issues/1)。覆盖用户故事：31、34、55、57、60。

## What to build

文章中的 Notion 托管图片及外部图片在同步时成为博客自己的静态资源，读者无需登录 Notion，临时地址过期后仍能阅读图片。

## Acceptance criteria

- [ ] 从 Notion 正文中的图片及图片引用读取实际资源，下载后校验内容并持久化，不只复制临时签名链接。
- [ ] 转换后的文章及真实构建 HTML 引用博客静态资源，图片地址遵守现有部署基础路径。
- [ ] 保留图片在正文中的位置、文字说明及可取得的替代文本，手机与桌面图片可阅读。
- [ ] 相同资源可去重，源临时签名变化不生成重复博客文章，也不使最终页面依赖临时源地址。
- [ ] 下载、鉴权、格式校验或持久化失败报告文章和资源，整次失败保留旧文章、列表及图片。
- [ ] 可控图片返回通过真实同步、下载处理和构建验收；验证源签名链接不可用后，已发布静态图片仍可读取。
- [ ] 用真实代表文章核实图片读取与匿名访问，测试固定数据及静态资源不含访问凭据。
