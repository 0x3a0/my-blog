# 01：打通首篇 Notion 文章的完整同步

状态：已发布 [GitHub Issue #2](https://github.com/0x3a0/my-blog/issues/2)；实现与剩余验收见[验收记录](../NOTION_ACCEPTANCE.md)。

## Parent

[Notion 正式规格 #1](https://github.com/0x3a0/my-blog/issues/1)。覆盖用户故事：1–9、12–15、23–28、35–40、42、51、53、56–58、60。

## What to build

作者在 My blog 勾选一篇普通文章后，运行一次同步即可在首页、归档和稳定地址的详情页阅读最新保存内容。复用现有页面、图片处理接口及候选构建保护，将只读探针能力接入真实同步入口。

## Acceptance criteria

- [ ] 从明确的文章数据库及数据源读取；多个数据源时要求明确选择，源页面不必 Publish to web，也不改写源文章或属性。
- [ ] 验证 to-blog-site 是复选框，只选 true；未勾选文章不公开，选择字段缺失或错误不得当作可信空集合。
- [ ] 完整分页读取，不以第一条文章或画廊视图代替发布集合；重复页面身份不产生重复博客文章。
- [ ] 普通文章的唯一标题、基本属性、纯日期 Published 与最新保存正文进入真实内容集合，文章地址由稳定页面 ID 决定；最后编辑时间仅参与同步检查。
- [ ] 同一文章后续保存和改标题更新原地址；读取期间状态变化时有限重读，无法取得一致状态则失败，不拼接不同版本或回退旧正文。
- [ ] 用一篇含中文、普通标题和段落的代表文章跑通真实 Astro 构建：首页、归档、详情和基础路径下的目录链接可访问，属性不混入正文。
- [ ] 读取、鉴权、正文缺失或构建失败保留完整旧快照；未覆盖的转换或撤回场景明确失败，不提交缺损或不可信结果。
- [ ] 以可控 Notion 返回运行真实同步及构建测试，并核实一次真实授权读取；凭据与验证正文留在忽略路径，不进入日志或网站。

## Blocked by
