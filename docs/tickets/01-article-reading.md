# 01：从首页进入可阅读的文章详情页

状态：待确认，尚未发布。对应规格用户故事：39、41、42、51、52、53、58、60。

## Parent

[语雀同步、文章详情与按年归档规格 #1](https://github.com/0x3a0/my-blog/issues/1)。

## What to build

读者可以从首页最新五篇进入真实文章详情，看到标题、创建日期、更新时间与基础正文。先使用本地代表文章走通内容集合、静态页面与构建，保留已有首页视觉，为后续语雀文章复用同一阅读路径。

## Acceptance criteria

- [ ] 首页最多展示五篇真实文章，按文章创建日期倒序；每篇标题链接进入对应详情页。
- [ ] 详情页由现有文章集合静态生成，展示标题、创建日期、可用的更新时间及基础正文；空集合显示真实空状态，不将预览样例冒充已发布文章。
- [ ] 复用现有文章地址构造能力；同一文章身份的标题修改不改变地址，未知文章地址不提供正文。
- [ ] 日期显示与年份计算统一使用 Asia/Shanghai，覆盖 UTC 与北京时间跨日、跨年的代表场景；修改文章不重写创建日期。
- [ ] 首页到详情的链接在站点根路径和 GitHub Pages 子路径下均有效，桌面与移动端基础布局可阅读。
- [ ] 通过真实内容集合与静态构建检查最终页面、日期、链接及空状态；使用现有技术栈与依赖，不为本任务单独升级依赖。

## Blocked by
