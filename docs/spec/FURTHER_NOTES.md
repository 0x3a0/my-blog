# 交接说明

## 发布与测试状态

规格已发布为 [GitHub Issue #1](https://github.com/0x3a0/my-blog/issues/1)，已应用 `ready-for-agent` 标签。任务跟踪器、标签映射及领域文档规则见[工程技能配置](../agents/README.md)。

用户已确认主要测试入口：使用可控语雀返回，运行真实同步及静态构建，检查最终文章、页面、资源与失败保留行为。没有运行尚未实现功能的测试。

Issue 已按规格模板展开全部 60 项用户故事、实现决定与测试要求，可独立阅读；本地短章节继续作为仓库中的规格入口。

## 接入前提

实际接入还需指定知识库、博客发布分组和具有相应读取权限的凭据，并完成最新保存内容与元数据保留验证。凭据不写入规格、文章或静态网站。

接口不满足已确认规则时，记录实际能力缺口并重新讨论，实现不能擅自更换内容版本或降低保真要求。

## 文档组织

当前规格采用主文档与短章节，遵循项目渐进式披露要求。全部已讨论的产品规则进入规格，不再展开产品访谈；实现步骤与细节由对应章节提供。
