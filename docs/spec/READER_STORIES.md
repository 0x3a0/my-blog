# 读者：归档与阅读

41. 作为读者，我希望首页继续展示最新五篇文章，以便快速了解最近内容。
42. 作为读者，我希望点击首页文章进入详情页，以便阅读全文。
43. 作为读者，我希望 Header 显示 blogs，以便找到全部文章入口。
44. 作为读者，我希望归档按年份分组，以便按时间浏览历史内容。
45. 作为读者，我希望年份从新到旧排列，以便先看到近期文章。
46. 作为读者，我希望同一年内文章按日期倒序，以便继续按时间浏览。
47. 作为读者，我希望全部文章直接展示，以便无需翻页就能查阅归档。
48. 作为读者，我希望每行显示标题、分类和跳转箭头，以便清晰地选择文章。
49. 作为读者，我希望归档布局沿用参考图的留白与分隔线，以便列表易于扫描。
50. 作为读者，我希望在手机上也能清晰浏览年份与标题，以便随时阅读。
51. 作为读者，我希望进入详情页后看到标题、文章日期与更新时间，以便了解内容与时效。
52. 作为读者，我希望带时间的日期与归档年份按北京时间计算、纯日期保持填写日，以便日期展示一致。
53. 作为读者，我希望文章日期来自作者填写的 Published，以便旧文章保留原有时间位置。
54. 作为读者，我希望通过文章目录跳转到正文标题，以便快速定位内容。
55. 作为读者，我希望正常阅读图片、代码块、表格与引用，以便理解完整文章。
56. 作为读者，我希望正文不混入 Notion 属性栏目，以便集中阅读文章内容。
57. 作为读者，我希望无需登录 Notion 就能阅读博客文章与图片，以便直接访问公开内容。
58. 作为读者，我希望收藏的文章链接在改标题后仍然有效，以便再次访问。
59. 作为读者，我希望撤回文章的旧链接不再展示正文，以便网站反映作者的发布选择。
60. 作为读者，我希望链接、目录和图片在现有部署基础路径下正常工作，以便从任一入口顺利阅读。
