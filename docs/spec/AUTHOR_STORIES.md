# 作者：内容与发布选择

1. 作为作者，我希望在 Notion 写文章，以便在云端多端维护同一来源。
2. 作为作者，我希望在 Notion 修改标题、属性和正文，以便内容只维护一份。
3. 作为作者，我希望首版连接现有 My blog 文章库，以便沿用当前整理方式。
4. 作为作者，我希望每张卡片对应一篇独立文章，以便继续使用 All blogs 画廊。
5. 作为作者，我希望 to-blog-site 是默认不勾选的复选框，以便新文章不会自动公开。
6. 作为作者，我希望只有勾选文章进入博客，以便明确选择公开内容。
7. 作为作者，我希望未勾选笔记、草稿和模板不进入博客，以便保留私密内容。
8. 作为作者，我希望源页面无需 Publish to web，以便写作页面可以保持私密。
9. 作为作者，我希望勾选表示允许博客公开，以便自行控制公开边界。
10. 作为作者，我希望取消勾选、移出文章库或放入回收站可撤回，以便结束公开展示。
11. 作为作者，我希望成功撤回同时移除列表和详情正文，以便旧链接不继续提供正文。
12. 作为作者，我希望同步最新保存内容，以便无需另外执行发布步骤。
13. 作为作者，我希望勾选期间后续保存也会同步，以便持续修改已公开文章。
14. 作为作者，我希望页面标题是唯一标题来源，以便改名后博客标题更新且地址不变。
15. 作为作者，我希望元数据在 Notion 属性中维护，以便无需在正文编写 YAML。
16. 作为作者，我希望 description 使用文本属性且允许空值，以便自行决定是否填写摘要。
17. 作为作者，我希望 category 使用单选属性且允许空值，以便自行决定文章分类。
18. 作为作者，我希望 Published 由自己填写，以便决定文章日期及归档位置。
19. 作为作者，我希望空 description 保持空值，以便博客不自动生成摘要。
20. 作为作者，我希望空 category 保持空值并显示“未分组”，以便缺省展示不改写源属性。
