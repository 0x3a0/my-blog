# 作者：内容与发布选择

1. 作为作者，我希望在语雀编写文章，以便继续使用现有写作工具。
2. 作为作者，我希望在语雀修改正文，以便只有一个内容来源。
3. 作为作者，我希望首版连接一个指定知识库，以便集中管理博客内容。
4. 作为作者，我希望建立“博客发布”分组，以便明确哪些内容可以公开。
5. 作为作者，我希望放入该分组的文章被同步，以便通过目录操作选定内容。
6. 作为作者，我希望子分组中的文章也被同步，以便保留自己的整理层级。
7. 作为作者，我希望其他位置的笔记和草稿留在语雀，以便只公开选定内容。
8. 作为作者，我希望选定文章可在语雀保持私密，以便知识库公开性与博客发布选择相互独立。
9. 作为作者，我希望分组选择代表公开授权，以便自行决定博客的公开内容。
10. 作为作者，我希望移出选定分组能撤回博客文章，以便结束公开展示。
11. 作为作者，我希望撤回同时影响列表与详情页，以便旧链接也不再提供正文。
12. 作为作者，我希望同步最新保存内容，以便不必额外产生语雀已发布版本。
13. 作为作者，我希望留在分组中的后续保存也会同步，以便持续维护博客文章。
14. 作为作者，我希望修改语雀标题能更新博客标题，以便标题只维护一份。
15. 作为作者，我希望正文开头可填写元数据，以便在语雀维护博客文章属性。
16. 作为作者，我希望填写 description 指定摘要，以便准确概括文章内容。
17. 作为作者，我希望填写 category 指定分类，以便分类表达文章主题。
18. 作为作者，我希望元数据与整段 frontmatter 都可省略，以便旧文章直接接入。
19. 作为作者，我希望缺少摘要时自动使用语雀摘要或正文摘要，以便减少补写工作。
20. 作为作者，我希望缺少分类时默认为“随笔”，以便文章始终有清晰的分类展示。
