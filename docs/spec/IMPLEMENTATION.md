# 模块与接口

## 同步 Module

新增同步 Module，以一次同步任务作为主要 Interface。它接收指定知识库、博客发布分组、鉴权及输出配置，生成一份候选内容与资源快照，报告成功、失败与未支持项。

将选定、去重、最新内容读取、元数据提取、格式转换、资源处理及撤回判断封装在此 Module 内。语雀读取的 Adapter 在同一 Seam 可替换为测试返回；调用者无需操作内部解析步骤。

## 内容与构建

复用现有本地 Markdown 内容集合、文章排序和地址构造能力。作者元数据只需 description 与 category；标题、创建日期、更新时间和稳定身份由同步结果补齐。日期与按年归档统一使用北京时间。

候选快照在隔离输出中生成，经完整内容校验及现有静态构建成功后才进入发布流程。失败退出，保留上次线上站点；完整成功时统一生效新增、更新和撤回。可信空集合是正常空状态，不把预览样例当成已同步的真实文章。

## 页面与部署

增加详情 Module 和按年归档 Module，修改 Header 与首页文章入口，复用现有布局、正文渲染、静态构建及 GitHub Pages 发布流程。保留既有首页视觉，按参考图实现归档布局。

自动同步与构建发布使用同一候选结果，计划在每日北京时间 06:00 触发。凭据只提供给同步执行环境。具体文档和资源链接遵守现有部署基础路径。

继续使用固定技术栈。元数据解析优先复用已有 Astro 解析工具；格式结构与字段校验覆盖缺少结束分隔线及非映射对象等情况。
