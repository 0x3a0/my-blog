# 模块与接口

## 同步入口

以“一次 Notion 同步”为主要公开入口，接收文章库、明确的数据源、读取授权及站点输出配置，生成完整候选内容、资源和发布结果。封装枚举、选择、校验、最新正文、转换、资源及撤回，调用者不操作内部步骤。

外部 Notion 读取适配器在这一入口可替换为可控返回；真实同步、内容集合和静态构建仍参与测试。保留现有通用快照发布器的准备接口，不为解析或排序增加单独测试接口。

## 内容与页面

复用现有 Markdown 内容集合、文章排序、稳定地址、首页、详情与归档。作者属性映射为摘要、分类和文章日期；页面身份、唯一标题和最后编辑时间来自源页面。生成文件可携带构建元数据，但作者不必填写正文 YAML。

纯日期保持填写日，带时间统一北京时间，区间取起始日期；未来日期不控制发布。标题变化不变地址，日期修改可以改变归档位置。同日期文章以稳定身份排序，保持输出可重复。

转换 Notion 扩展 Markdown，支持普通标题、列表、图片、代码、表格与引用；提示框转引用、分栏单列。先完整确定本次文章集合，再转换内部文章链接；子页不展开。空正文有效，缺失或无法转换内容必须失败。

## 完整快照与部署

复用隔离候选构建和必需图片本地化。候选包含本次完整选定文章集合，不能将撤回后的旧内容混入新快照。读取、校验、资源及真实 Astro 构建全部成功后整体提交；失败保留旧输出及线上站点。

复用 GitHub Pages 基础路径与发布流程，将每日北京时间 06:00 的计划触发加入同步、构建、部署流程；只上传成功候选，失败不得部署空结果或部分结果。凭据只提供给执行环境，避免并发任务相互覆盖。

保持 Astro SSG、严格 TypeScript、Tailwind CSS 4、daisyUI 与 pnpm，优先复用现有依赖。现有页面、图片转换及快照保护是实现先例，不代表 Notion 正式同步已经完成。
