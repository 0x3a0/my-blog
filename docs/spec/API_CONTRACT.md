# 语雀读取契约

依据项目提供的本地 OpenAPI 文档；接口能力摘要见[语雀接口要点](../YUQUE_API.md)。

## 可确定能力

目录提供文档、外链与分组节点及父子关系，文档身份可与目录节点关联。文档列表支持分页，单页最多 100 条。普通详情包含标题、创建时间、内容更新时间、内容格式、草稿正文及其他正文表示。

鉴权使用 X-Auth-Token，私密内容是否可读取决于具体读取权限。“博客发布”分组中的选定是博客公开授权；语雀的草稿或私密状态不会自行取消这一授权。

## 必须先验证的契约

用真实代表文章核验首次保存、已发版、保存未发版修改、清空正文及修改标题。确定可可靠获取最新保存正文及其对应标题、更新时间和格式；核验正文开头的分隔线与 YAML 是否保留，以及必需图片能否用于公开阅读。

body_draft、body、body_html 的说明不足以证明它们都反映最新保存状态。空字符串含义及字段缺失须区分。获取不到可靠最新内容时报告能力缺口，不能回退历史正文冒充最新版。

## 读取结果与错误

Adapter 区分可信的完整读取结果、未支持的非文章类型和读取失败。完整结果才能用于撤回判断；缺失配置、目录无法唯一确定、分页未完成、无权限或接口异常均是失败。

候选文章必须对应普通文章；外链节点不当作正文。独立工作表、画板和数据表列为未支持项。普通文章无法可靠转换或必需资源无法获取属于任务失败。
