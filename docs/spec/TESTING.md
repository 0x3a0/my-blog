# 测试方案

## 已确认的主要入口

沿用用户已确认的“一次同步任务 → 候选内容 → 真实静态网站”。Notion 读取适配器提供可重放返回，测试调用真实同步入口及现有内容集合、图片处理和 Astro 构建。

只断言外部行为：文章、资源、最终 HTML、成功失败结果及旧站点完整性。不替换内部属性解析、排序、转换或撤回逻辑，不依赖内部调用顺序；内部重构后相同行为仍须通过。

## 覆盖与先例

测试同步模块的公开入口，并检查首页、Header、归档、详情及资源输出。现有 Node 内置测试与真实快照构建是先例：三项通用集成测试覆盖空元数据、正文资源、失败保留及空快照撤回；它们不证明 Notion 接入完成。

可控读取覆盖复选框选择、属性缺省及错误、分页、最新保存修改、日期边界、空正文、内部链接、特殊排版、撤回和权限变化；真实构建与图片失败都要验证整站保留，见[验收场景](./TEST_CASES.md)。

## 真实读取与页面验收

正式接入先用真实代表文章核验授权、中文、标题及属性、保存修改、清空正文、列表分页、普通正文及临时图片。常规自动测试使用去除凭据与个人内容的固定返回，不依赖真实账号或生产部署。

桌面与手机检查归档参考布局、长标题、目录、代码、表格及图片。部署验收验证每天北京时间 06:00 的计划触发、站点基础路径，以及失败任务不上传或部署候选产物。规格整理不新增或运行功能测试，也不将需求确认当作实现验收。
