# 验收场景

## 选定与更新

- 分组与子分组中的普通文章全部导入；分组外文章不导入；重复文档引用只生成一篇文章。
- 私密且选定的文章在读取权限有效时导入。权限错误使任务失败，不产生下架变更。
- 已选定文章首次保存、保存未发版修改及修改标题，都同步经验证的最新内容，文章地址不变。
- 空正文按已验证的源语义处理，不能因简单回退重新发布旧正文。
- 多页读取完成后才提交完整快照；目录或分页失败保留旧站点。

## 元数据与资源

- frontmatter description 优先；缺省时使用语雀摘要，再缺省时从移除元数据的正文生成摘要。
- category 缺省为“随笔”；目录位置不自动变成文章分类。标题唯一来自语雀文章标题。
- 无 frontmatter 正常处理；合法 frontmatter 被提取且不出现在正文；错误 YAML、未闭合块或非预期结构使任务失败。
- 图片、代码块、表格、引用与正文目录正常显示；必需图片失败阻止整次发布。
- 独立工作表、画板和数据表不导入，并有未支持项报告。

## 撤回与原子发布

- 移出选定范围后，成功同步同时移除列表入口和详情正文；其他文章不受影响。
- 某篇文章转换失败、资源失败或静态构建失败，均阻止整次发布，旧站点完整保留。
- 即使本次包含撤回操作，其他错误也不能造成部分更新或部分下架。
- 完整成功且选定集合为空时，显示可信空状态；不会把示例内容冒充真实文章。

## 页面与日期

- Header 的 blogs、首页最新五篇和归档各行都能进入对应页面；部署在站点子路径时链接与资源仍正确。
- 按北京时间确定日期与年份，覆盖 UTC 日期与北京时间跨年不一致的场景。
- 年份与年内文章按日期倒序，全部文章一次展示；归档行仅有标题、分类与入口，无摘要、分页或分类筛选。
- 更新文章不改变创建日期与原始年份归属；详情显示标题、创建日期、更新时间、正文和目录。
- 桌面端年份在左，文章在右；手机端年份位于组内文章上方，标题、代码和表格可正常阅读。
