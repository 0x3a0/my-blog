# 验收场景

## 选定与更新

- 仅文章库中 to-blog-site = true 的文章公开。
- 最新保存标题、属性和正文进入下次同步，标题修改不改变地址。
- 修改 Published 可改变排序和年份归属；正文编辑仅更新最后编辑时间。
- 完整分页与权限有效才提交；异常保留旧站点。
- 默认未勾选的新文章不公开；缺失或错误的选择属性不能造成全站下架。
- 同一页面重复返回或任务重试不生成重复文章，读取期间变化不能拼接不同版本。

## 属性与资源

- 页面标题是唯一标题来源，元数据来自属性。
- 空 category 保持空值、显示“未分组”；空 description 保持空值、不生成摘要。
- Tags 和 AI custom autofill 不自动映射成分类或摘要，不写回缺省值到 Notion。
- 选定文章 Published 必填，缺失时整次失败并指出文章。
- 未来 Published 不阻止发布，仍按该日期显示、排序及归档。
- Published 纯日期保持作者填写日；带时间按北京时间；区间只用起始日期，覆盖跨年边界。
- 图片、目录、代码、表格和引用可阅读，必需资源失败阻止发布。
- 提示框转为引用，分栏按顺序转为单栏，保留文字及基本结构。
- 子页面不展开；本次同步文章的链接转博客地址，其余保持源链接。
- 空正文同步清空旧正文，详情保留标题与属性。
- 范围外或无法完整转换的正文指出文章和内容类型，整次失败保留旧站点，不静默丢内容。
- 截断、未知块及缺失正文不当作空正文；纯文本、中文、列表及扩展表格转换后内容完整。
- 所有必需图片持久化，最终 HTML 不依赖会过期的源图片地址，匿名读者可访问。

## 撤回与页面

- 取消勾选、移出库或回收站后，成功同步移除列表和详情正文。
- 内容、资源或构建失败保留整个旧站点，包括计划撤回的文章。
- 可信空集合显示空状态，异常不能作空集合。
- Header 的 blogs、首页最新五篇、归档与详情遵守部署基础路径。
- 按北京时间显示日期与年份，年份及年内文章倒序，全部文章按年展示。
- 桌面年份在左，手机年份在组上方，归档不新增分页、筛选、搜索或摘要。
- 每日北京时间 06:00 配置计划触发，失败不上传或部署空站点；触发不承诺准时完成。

以上是已确认的验收要求。当前已通过的测试和仍待完成的真实验收见[验收记录](../NOTION_ACCEPTANCE.md)。
