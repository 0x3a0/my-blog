# 问题与方案

## Problem Statement

作者习惯在云平台写作并多端同步，需要免费读取自己的文章、明确控制哪些内容公开，并自动同步后续修改。现有博客首页已经建立，详情、归档与通用发布保护有本地代码；尚未通过 Notion 实现完整自动同步，也未完成真实接入验收。

## Solution

沿用现有 Notion My blog 文章库及 All blogs 画廊，每个条目是一篇独立源文章。添加默认不勾选的 to-blog-site 复选框，只同步明确勾选的文章；源页面可以保持私密，只需授权读取连接，无需 Publish to web。

在 Notion 修改标题、属性和正文，博客每日北京时间 06:00 计划读取最新保存状态，无额外确认发布步骤。标题唯一取自页面标题；description、category、Published 通过属性维护，不要求正文 YAML。取消勾选、移出文章库或放入回收站后，下次完整成功同步统一下架。

首页保留最新五篇，Header 提供小写 blogs，归档按年倒序分组、年内按文章日期倒序，一次展示全部文章。桌面年份在左、文章行在右，手机年份在组上方；文章行显示标题、分类和箭头，用细线及组间留白分隔。

详情页展示标题、文章日期、正文与目录，支持普通文章的图片、列表、代码、表格和引用。提示框转引用、分栏转单栏；空正文清空旧正文，子页面不自动展开。标题修改后链接保持稳定。

同步在隔离候选中准备内容、持久图片及真实静态构建；全部成功后统一发布新增、更新和撤回。读取不完整、属性错误、范围外内容、转换、必需图片或构建失败时，报告原因并保留上一次完整网站。
