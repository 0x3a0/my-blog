# 文章页面

本文说明[功能规格](./spec/README.md)中的页面规则。

## 详情页

首版包含标题、发布时间、正文、文章目录，以及图片、代码块和表格的阅读样式。

文章日期沿用语雀创建日期；后续修改只更新“更新时间”。两者均按北京时间展示。

首版聚焦普通文章，支持图片、代码块、表格与引用。独立工作表、画板、数据表等暂不导入，并在同步结果中列出。

## 全部文章

增加全部文章页面，提供所有已发布博客文章的浏览入口。Header 中显示 `blogs` 导航，点击进入全部文章页面。

按年份分组，年份从新到旧排列，同一年内按文章日期倒序排列。参考用户提供的归档截图：桌面端左侧显示年份，右侧逐行显示文章标题、分类与进入详情页的箭头，文章行之间有细分隔线，年份组之间留出较大间距。

全部文章直接在该页面展示，首版不分页，不增加分类筛选或搜索。列表行不展示摘要；移动端将年份放在该组文章上方，保持标题清晰可读。

![按年份分组的归档参考](./references/blogs-archive.png)

首页继续展示最新五篇文章。

文章分类由作者在语雀正文开头的元数据中填写，见[文章元数据](./ARTICLE_METADATA.md)。
